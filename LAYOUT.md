# Layout lock — Бюро 1440 / Рассвет (публичный сайт)

Агентам и людям: **не импровизировать отступы и шрифты**. Один каркас, один ритм.

## Готовые правила (уже в Cursor)

1. **Обучающие сайты** → `.cursor/rules/educational-sites-style.mdc` (ОУД4: Unbounded + Onest, crimson, shell).
2. Этот файл — **локальный лок** для тёмного космического слоя `theme-orbit.css`.

## Токены (не плодить новые)

| Токен | Назначение |
|--------|------------|
| `--shell` 1120px | ширина контента |
| `--gutter` 1.5rem | боковые поля |
| `--space-1…5` | вертикальный ритм (см. `layout-lock.css`) |
| `--font-display` | Unbounded — только H1/H2/kicker/цифры |
| `--font-body` | Onest — весь остальной текст |

## Компоненты (использовать эти классы)

| Класс | Что это |
|--------|---------|
| `.block` + `.block-head` | секция: kicker → h2 → lead |
| `.block--tint` | чередование фона |
| `.orbit-shell` | 2 колонки: сцена + сайдбар |
| `.orbit-callout` | короткая карточка-пояснение |
| `.problem-card` / `.challenge` | сетка фактов |
| `.btn--primary` / `--ghost` / `--light` | кнопки |
| `.term` | термин с подсказкой (не ссылка на md) |

## Запрещено на публичной странице

- Ссылки вида `docs/*.md`, `data/*.json` в UI (это репозиторий, не продукт).
- Свои `margin-top: 2rem` / `padding` в инлайне без токена.
- Третий шрифт, синие дефолтные ссылки Office, «карточки ради карточек».
- Разный `max-width` у соседних секций.

## Как править

1. Правь контент внутри готовых блоков.
2. Отступы — только `--space-*` или существующие классы.
3. Нужен новый вид блока → добавь класс в `layout-lock.css` / `theme-orbit.css`, не копируй разовые стили.
