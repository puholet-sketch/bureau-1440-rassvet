# Бюро 1440 — досье компании

Срез: **2026-10-24**. Канон JSON: `data/company.json`.

## Кто это

Российская аэрокосмическая компания в контуре **ИКС Холдинг**. Разрабатывает и будет оперировать низкоорбитальной группировкой **«Рассвет»** для широкополосной связи (аналог класса Starlink/OneWeb по архитектуре LEO mesh).

Название: **1440** — отсылка к числу витков первого Спутника вокруг Земли.

## История кратко

1. **2020** — проект «МегаФон 1440».
2. **2021** — частоты Ku/Ka (ГКРЧ).
3. **2022** — переход в ИКС Холдинг → «Бюро 1440»; МегаФон остаётся партнёром.
4. **2023** — Рассвет-1 (3 КА).
5. **2024** — Рассвет-2 + квалификация лазерных ISL.
6. **2025–26** — серийное производство / ЗИЛ; первые пакетные запуски Рассвет-3 (по 16 КА).

## Структура и численность

- Холдинг: ИКС (смежные компетенции — **Yadro** для радиоэлектроники и ядра сети).
- Вертикаль внутри Бюро: платформа КА, лазерные терминалы, плазменные ДУ, абонентские терминалы, шлюзы, ЦУП.
- Штат: **>3000** (заявление руководства, 2026); среднесписочная ФНС **2187** (2025).
- ~80% — инженеры / высокотехпроизводство; средний возраст ~33–34.
