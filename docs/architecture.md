# Как работает связь «Рассвет»

Срез: **2026-10-24**. Параметры: `data/tech-params.json`. Живая схема: `viz/index.html`.

## Цепочка данных (абонент → интернет)

```text
Телефон/ПК
  → Wi‑Fi / LAN абонентского терминала (АФАР 60×60 см)
    → RF uplink Ku/Ka к спутнику над вами (~510–800 км)
      → onboard 5G NTN (регенерация, «базовая станция на орбите»)
        → лазерная межспутниковая mesh (до 10 Гбит/с, 30–1005 км)
          → КА над шлюзовой станцией
            → Ka feeder downlink
              → шлюз → ядро сети / интернет
```

Обратный путь зеркален. Без лазерных ISL каждый КА должен видеть шлюз; с ISL пакет «прыгает» по орбите до удобного шлюза (критично для Арктики, морей, удалённых регионов РФ).

## Параллельный контур управления

Станции слежения (ТМИ/команды) ↔ **ЦУП** Бюро 1440: ориентация, плазменная ДУ (подъём с ~300 км, удержание), здоровье КА, SSA.

## Спутники

| Поколение | Масса | Роль |
|-----------|-------|------|
| Рассвет-1 | ~80 кг | эксперимент 2023 |
| Рассвет-2 | ~120 кг | 5G NTN + лазер ISL 2024 |
| Рассвет-3 | ~370 кг | серия: 5G NTN, ISL new gen, плазменная ДУ |

## Плазменный двигатель

Электрическая ДУ на **криптоне** (по открытым сводкам): малая тяга, высокий Isp → медленный подъём с опорной ~300 км на рабочую орбиту (недели–месяцы), затем поддержание против атмосферы и манёвры.

## Лазерная ISL

Собственные терминалы; лётная квалификация на Рассвет-2: **10 Гбит/с**, дистанции **30–1005 км**, BER < 10⁻¹¹. Узкий ИК-луч: сложно перехватить/заглушить с Земли; требует точного наведения (acquisition → tracking).

## Наземка

- Абонент: **1440.УЛЬТРА** — до 700 Мбит/с, 11 кг, IP67, −40…+40 °C.
- Шлюзы + ядро (синергия Yadro / операторы вроде МегаФон).
- Ранний сегмент: **5** станций слежения по РФ.

## Орбита и покрытие

- Маркетинг: **~800 км**, задержка до **~70–100 мс**, скорость до **1 Гбит/с**.
- Серия по трекингу (2026): **~510 км**, наклонение **~82.3°** (Россия + высокие широты).
- Один КА на 510 км видит пятно ~**885 км** радиуса (оценка при min elev 25°). Для бесшовного покрытия нужно **250+** активных аппаратов.
