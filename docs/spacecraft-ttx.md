# Спутник «Рассвет»: вид, двигатели, ТТХ, сборка, видео

Срез: **2026-10-25**. JSON: `data/spacecraft.json`.

## Как выглядит

Компания почти **не публикует** официальные фото/рендеры серийного **Рассвет-3**. По открытым разборам и неофициальным схемам:

- плоская платформа «плита» (класс Starlink V1.5), но с **меньшими** солнечными панелями;
- раскрываемые СБ по бокам корпуса;
- user-антенны (фазированные панели) + заметные **Ka feeder** («лопухи»);
- лазерные терминалы ISL (узлы наведения на корпусе);
- плазменная ДУ для подъёма с опорной орбиты.

Оценки габаритов (не заводские ТТХ): ширина корпуса ≈**1,2–1,4 м**, толщина ≈**0,35 м** при укладке пакета в обтекатель «Союз»; длина/размах СБ в прессе — порядка **~4 м / ~10 м**.

Экспонат **Рассвет-1** показывали на выставке «При чем тут космос» (Музей криптографии).

## Полный состав систем (серия)

1. **Платформа** — своя, под серию; своя система отделения пакета.
2. **5G NTN** — Ku + Ka, регенеративная «БС на орбите».
3. **Лазер ISL** — свои терминалы; квалификация **10 Гбит/с**, **30–1005 км**.
4. **СЭС** — СБ + АКБ («обновлённая» на серии); мощность не раскрыта.
5. **Плазменная ДУ** — криптон (по сводкам); подъём 300→рабочая, удержание.
6. **Ориентация / GNSS** — для АФАР и лазера; навигаблок отработан на Рассвет-2.

## Плазменный двигатель — принцип

1. В камеру подаётся рабочее тело (**Kr** / иногда Xe в отрасли).
2. Газ ионизируется → **плазма**.
3. Магнитное поле удерживает электроны (**эффект Холла**).
4. Электрическое поле разгоняет ионы → слабая, но очень экономичная тяга.

Тяга — **граммы силы**, манёвр — **недели–месяцы**. Модель Бюро 1440 не названа; в прессе сравнивают с классом **СПД-70** (~4 гс) / **СПД-100В** (~9 гс).

Оценка Δv: ~**120 м/с** до 510 км, ~**275 м/с** до 800 км.

## Где собирают

- **Технопарк ЗИЛ (Москва)** — инж.-произв. центр ИКС: ~47 тыс. м², из них >70% под Бюро 1440, опытное производство ~**15 тыс. м²**, лаборатории, R&D.
- Локализация критических узлов (СЭС, связь, ДУ) «под серию» с партнёрами; синергия с **Yadro**.
- Пуски: **Плесецк**, РН **Союз-2.1б**, пакет ~16 КА на опорную ~300 км.
