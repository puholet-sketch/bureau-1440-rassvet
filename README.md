# Бюро 1440 · Рассвет — интерактивное досье

Публичная витрина открытых данных по российской LEO-группировке «Рассвет» (Бюро 1440):
схема связи телефон→спутник→Земля, ТТХ, финансы, команда, покрытие, среда на орбите, плазменные ДУ.

**Live:** https://puholet-sketch.github.io/bureau-1440-rassvet/

Не официальный продукт Бюро 1440. Источники — в data/sources.json.

## Локально

Откройте index.html или:

`ash
python -m http.server 8766
`

## Структура

- index.html — интерактивная схема и разделы
- docs/ — текстовые разборы
- data/ — JSON-канон
